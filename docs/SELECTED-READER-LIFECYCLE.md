# Selected source reader lifetime

Selected-source privacy-check metadata, source hydration and active historical-original validation now own their actual detached reader and actor completion through cancellation, external drain, Quit, library switching, wipe and encrypted lock. Replacing or dismissing a selection cancels the older worker while retaining its shutdown ownership until it really returns.

## Behavior

The library worker registry holds each finite read. Canceling a returned metadata observer forwards cancellation to the actual worker and still joins it. Canceling an external-drain caller cannot acknowledge unfinished work or admit a new reader. Closed, retired and draining workspaces refuse new reads; canceled or obsolete completions publish no old selection, privacy status or error.

An idle historical-validation timer is not ongoing exit work. Each active validation is registered separately; its result must still match the exact original and recap. External drain cancels the loop, invalidates selection generations and clears the pending source-opening identity, so the loop cannot restart after drain returns. Historical erasure still closes the selected original. Hydration keeps its original user-initiated priority; metadata and validation use utility priority.

The selected privacy-check record remains separate from source hydration. Missing or failed metadata stays an explicit unavailable record rather than becoming an unchecked privacy claim. Original evidence is never replaced by a current source with the same native identifier.
