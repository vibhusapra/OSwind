# Architecture

Swift package targets:

- `OSwindCore`: durable store, privacy policy, embeddings/retrieval, model adapters, screen/audio capture, API and MCP protocol.
- `OSwind`: SwiftUI app, AppKit menu/shortcut integration, setup/settings, source browsing.
- `OSwindCLI`: `oswindctl`, diagnostics, imports, benchmark, API/MCP host.
- `CSQLite`: system sqlite3 shim only. USearch 2.26.5 and resolved NumKong 7.8.5 supply the optional native HNSW graph; original source vectors remain in SQLite.

## Screen ingest

Foreground context → lock/idle/secure-field/app/title/URL checks → ScreenCaptureKit focused-window snapshot → small grayscale change signature → off-main Vision OCR → combine bounded Accessibility text → sanitize → suppress raw image if any text/title/URL was redacted → local embeddings → SQLite insert/FTS trigger → UI refresh.

One capture can be in flight. Pause/lock increments a generation token; in-flight work checks it before insert and deletes its image on cancellation. Full-display mode filters excluded apps and all browsers. Redaction is not a comprehensive DLP model. OS permission and URL extraction behavior need live testing per supported browser.

## Retrieval

Keyword queries are tokenized into quoted FTS terms (no raw SQL/FTS syntax). Date/app/kind/favorites/tag filters are SQL-bound parameters. Semantic search reads same-model, same-dimension vectors, computes Accelerate cosine scores and applies a minimum similarity. Apple Hybrid uses reciprocal-rank fusion (k=60). Optional Ollama embedding search uses cosine plus a bounded lexical-coverage bonus, preserving strong cross-language matches. Its Qwen3 query prefix follows the publisher instruction format. The Exact path is a linear vector scan. A precomputed query norm and direct SQLite-buffer scoring avoid per-vector copies. A bounded min heap retains only max(limit, 100) candidates, with deterministic score/time/ID ties. Updated per-model vectors take precedence over legacy same-model vectors. Automatic chooses the indexed path only for unfiltered archives with at least 20k vectors; all filtered queries remain exact after native predicate callbacks measured slower. Explicit Indexed can force approximate retrieval. Cold preparation, counts/statistics, write contention and million-record performance remain gates.

Schema 4 adds stable AUTOINCREMENT vector keys, per-model revisions, a mutation journal and store identity. Source/vector triggers cover legacy and multi-model writes. HNSW uses normalized float16 cosine vectors (connectivity 32, add expansion 128, search expansion 8192). Unpublished construction uses at most four CPU workers. The graph is a disposable cache, not a second evidence archive. Each query checks live SQL scope, source revision and model identity, reranks float32 candidates, and searches newer mutations exactly; excessive delta or unavailable cache falls back explicitly to exhaustive search. This protects source erasure while retaining approximate neighbor selection. A small recent-source sample improves ties; it does not guarantee globally exact approximate ranking.

Cache manifests bind store/model/dimensions/native format, sequence, count and SHA256 to immutable graph files. Directories are 0700, files 0600, symlinks rejected. A kernel lease prevents duplicate cross-process builders. Atomic manifests publish only a synchronized graph; corrupt/incompatible snapshots rebuild. Short read snapshots avoid holding a long WAL reader during construction. Manual cancellation pauses automatic construction; source vectors remain, partial graph construction restarts. Low-power/thermal gates defer building. Idle five-minute maintenance checkpoints only changed graphs, with power policy. Cache eviction precedes source pruning; Delete all clears files and rotates identity. Cache data is not application-vault encrypted. Hard-kill orphan cleanup, restore/fork lineage and cold-load tails remain release gates.

Memory JSON payloads store source metadata; embeddings are separate float32 blobs. Schema 2 adds a multi-model vector table keyed by memory ID and model identity (name, digest, preprocessing version and dimensions). Existing Apple vectors remain readable without reprocessing. Metadata edits preserve vectors; content changes invalidate the extra indexes. Network inference occurs outside SQLite locks, and batch saves compare content hashes to avoid storing stale results or resurrecting deleted records. Resumable 16-record batches retain completed work on cancellation. Automatic indexing is bounded and defers under low-power policy.

`RetrievalEngine` supplies one async search path to UI, Ask, CLI, HTTP and MCP, including coverage and fallback warnings. Keyword queries require no model server. Hybrid falls back explicitly to keyword search on model failure; semantic-only reports the failure. Local model URLs are loopback-only, redirects are refused and known remote/cloud model aliases are rejected before evidence is sent. These checks assume a trusted local daemon. OSwind-managed Ollama servers set `OLLAMA_NO_CLOUD=1`; an existing user daemon is not replaced or reconfigured.

Model discovery, streaming pulls, cancellation and GPU memory residency use Ollama APIs. Local generation and retrieval select independent models. The model manager starts an installed runtime; dependency installation remains in the setup script. No weights are bundled in Git.  SQLite WAL handles external readers. A process-local recursive lock serializes store operations. JSON imports run in a transaction, strip media paths, apply exclusions/redaction and rebuild vectors. Media paths reject traversal and symlink components and must live under `images/` or `audio/`.

## Audio

Microphone AVAudioEngine → AVAudioConverter to 16 kHz mono PCM. System audio SCStream → mono PCM. Each source accumulates a 30-second chunk. A simple RMS gate discards silence. At most three pending chunks; one whisper.cpp subprocess drains them with a time limit. Raw chunks are deleted after processing. Source labels remain distinct. Explicit Stop audio flushes a short final chunk; privacy Pause discards it and cancels pending inference. A one-second privacy timer stops audio when an excluded foreground context or lock is detected. Diarization, automatic meeting detection, audio-device changes and stronger continuous privacy tracking remain gaps.

## Answers

Query + date/app filters → up to 12 evidence memories → query-anchored bounded text excerpts → evidence-only, Apple FoundationModels, local Ollama, or explicit remote BYOK. Prompt separates untrusted source text and requests citations. Source cards are authoritative evidence; model prose must be checked. No agent tools or external writes are available to the answer engine. Full text/context hashes replace prefix-based duplicate suppression, preserving different decisions after shared boilerplate. Lexical windows favor rare query terms; a second passage can cover a distant term. Excerpts preserve composed Unicode, mark omissions, and remain bounded. Recaps/unanchored queries preserve opening and ending text. This does not solve semantic retrieval of a long source whose relevant tail was outside the embedding input. Chunked source vectors remain a separate gate.

Answer prompts keep only the current question and fresh evidence; recent user questions remain retrieval context. Apple uses guided claims in one request. A source-by-source experiment was discarded after generating a wrong owner despite valid citation numbers. Provider output-limit stop reasons fail before chat append. Plain explicit abstention can omit a citation. The setup preset pins Qwen3 Instruct 2507 Q4_K_M rather than a drifting short alias; observed latency/quality and failures are recorded in the benchmark ledger. Local Ollama requests do not read BYOK Keychain accounts.

## Saved conversations

Schema-3 sessions and turns live in the same SQLite database. Turn payloads contain the sanitized question/answer, warnings, provider, timing and explicit filter scope. Separate foreign-key links retain source IDs and citation order; source text is hydrated from the current memory row. Atomic append validates source text/context hashes plus timestamp/kind and session existence, preventing in-flight answers from reviving deleted/revised evidence or sessions. Source deletion/revision, including date/kind changes, removes citing turns and resets associated session titles. Retention deletes aged turns; Delete all clears sessions as well. Independent manual notes, clipboard copies and exports remain the user's separate copies.

Follow-ups use up to three recent user questions for subject context; retrieval includes the two most recent bounded questions plus the current question. Generation receives the current question and source excerpts; earlier questions affect retrieval/excerpt selection only. Earlier model prose is not evidence. Explicit current filters still apply, and the saved scope is shown per turn. App and CLI share this behavior; the HTTP/MCP interfaces remain memory-only. Apple uses [guided generation](https://developer.apple.com/documentation/foundationmodels/generating-swift-data-structures-with-guided-generation) for claims with source-number lists, rendered only after range validation. Other model prose gets citation warnings. Neither structural citation checking nor one successful follow-up demonstrates semantic grounding or broad abstention.

## Release risks

Current store schema is version 4, with version-1/vector, version-2/conversation and version-3/native-index preservation fixtures. Older binaries refuse the upgraded schema. Newer unknown schemas fail without downgrading. Future schema changes require migrations and fixture coverage. App binaries are locally ad-hoc signed, with no notarization/update service. Apple English sentence embeddings remain the default zero-download baseline. Optional Qwen3 multilingual results are measured on a small authored fixture; multimodal retrieval and robust no-evidence abstention remain gaps. Long-run power, pressure, permission revocation, audio hardware changes, and adversarial privacy testing require broader validation.
