# Folder activation and app erasure lifecycle — WIP

The pairing owner now offers an explicit shared-folder factory and saved-folder reconnect. It authenticates the existing signed object space (or explicitly creates a new one), prepares external delivery authority and native35 writer admission, and returns an initially paused session. Successful construction transfers pairing lifetime ownership to the session. Setup callers must retain/join the real operation and stop any late result before storage departure.

The local folder bookmark is nonsecret, bounded to64KiB and resolves without mounting or UI. It is separate from credentials and excluded by portable restore's content allowlist. Invalid bookmarks refuse without changing keys or content; explicit folder selection can repair them. A reserved delivery group cannot yet add members, revoke devices or rotate epochs. Admit intended members before connecting; a stopped session does not reset its original accounts.

Session erasure consumes the enrolled owner and requires the app to join all other producers first. A peer erase can only apply the exact signed control yielded by that session. Group review returns an opaque value bound to this session and captured local intent. Approval joins the worker and leaves processing suspended; the app must recheck current privacy/lock/network intent before resuming. A token cannot cross devices or a session reopen.

The public restricted recovery retry opens no ordinary library, migrations or provider transport. It verifies the saved original external retirement, cleans pending native files/pages, and renews only the exact completed receipt. Cancellation joins the actual work and an uncanceled close before returning. Missing/changed authority still refuses; recovery export remains independent.
