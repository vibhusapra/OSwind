OSwind uses a deterministic, explicitly mapped subset of the public validation split for local evaluation. Gold offsets are reconstructed only for unique exact literal occurrences; no normalization or fuzzy alignment is applied. Source data is synthetic; publisher annotations are not independently relabeled. No test split is used.

Raw dataset text and entity values are not distributed in Git. The public manifest contains hashes, labels and coordinate metadata only; full reproduction explicitly prepares the pinned public validation data locally.
